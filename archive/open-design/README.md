# Open Design archive

Archived by the owner's decision on 2026-10-28, from the integration candidate
following commit `4085ce3`. Earlier audits, readiness records, hashes and receipts
remain historical evidence; their original paths and verdicts are not rewritten.

Open Design is retained as a historical production stage and source archive.
It is not an active CENTURION route, skill, installer feature, bundle, MCP
registration, or runtime dependency. The active project keeps general design,
web-development, UI/UX, and media-generation skills; future work may replace
this archived stage with another explicitly approved adapter.

The archived bridge, producer skill, client wrappers, installer helper, bundle,
and their tests are preserved under this directory for historical inspection.
They are intentionally excluded from active surface audits and installations.

This directory preserves the former `integrations/` and `skills/` layout. Its
scripts and tests are frozen historical material, not supported installation
commands or current release gates. The active installer recognizes former owned
paths only to validate preimages and retire them safely; it never selects or
copies the archived package into a fresh client home. Modified owned files still
cause a conflict, and generated/user data is preserved.

General design and web roles such as `aedilis`, `pictor`, `nomenclator`, `orator`
and `tabularius` remain active. Native image/media-generation capabilities are
independent of this archived adapter and are selected from the actual consumer
catalog for an approved task.
