# Settings Snapshots

This directory stores sanitized, machine-readable summaries of local tooling
baselines that are useful for maintaining CENTURION integration kits.

Snapshots must not contain raw home config dumps, API keys, tokens, OAuth data,
cookies, authorization headers, private connection strings, machine or user
identifiers, raw permission allowlists, trusted project lists, memory contents,
or project history. Record only concise operational summaries needed to keep the
repository docs and integration kits aligned.
