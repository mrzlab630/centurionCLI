# CENTURION 3.0 — повторный локальный пилот, 17 октября 2026

**Кандидат 3.0.0-rc.1; установка в рабочую систему не выполнена.**
Новое окно разрешено ответом владельца «ок. делай». Оно продолжает
[предыдущую приёмку](CENTURION_3_0_LOCAL_READINESS_2026-10-17.md), не удаляя
неудачные попытки. Работа ведётся в `feat/centurioncli/v3-implementation`.

## Что исправлено по реальным запускам

1. Codex 0.163.0 принимает глобальный `codex --no-daemon exec`. Проверка
   команды теперь допускает именно этот вариант, сохраняя требования к модели,
   reasoning и sandbox. Вложенный bwrap с native Codex sandbox оказался
   несовместим; изолированный Codex использует собственный sandbox. Обязательный
   ограниченный proof запускает контроллер после ответа исполнителя.
2. Ошибка до `before_spawn` при сохранённом `reserved/not_started` без процесса
   больше не классифицируется как неизвестный эффект. Затраченная попытка
   сохраняется. Для действительно запущенного процесса прежний консервативный
   запрет повторного выполнения остаётся.
3. Каноническая JSON Schema содержала `allOf`, который native Structured Outputs
   отверг до выполнения инструментов. Генератор теперь выдаёт отдельную совместимую
   схему: закрытые объекты, обязательные поля, typed enum и вложенные `anyOf`.
   Каноническая схема и последующая семантическая приёмка не ослаблены.
4. Реальный ревизор вернул `pass`, но поместил пять положительных наблюдений в
   `findings`, предназначенные для незакрытых нарушений. Native-схема теперь
   различает три варианта: `pass` требует пустого списка, `fail` — непустого,
   `blocked` сохраняет обычный список. Положительные доказательства относятся к
   `proof`/`summary`. Контроллер не удаляет замечания из ответа модели и не
   превращает ошибочный ответ в одобрение.

Изолированное окружение Hermes регистрирует named custom provider с Responses.
Claude использует существующий native profile только для чтения и локальный
прокси с `ANTHROPIC_BASE_URL` и `ANTHROPIC_DEFAULT_OPUS_MODEL=claude-opus-5-5`.
Новые пароль, ключ, `/login` или публичный fallback не применялись. Это не
утверждение об отсутствии авторизации внутри HTTP-запросов native клиента.

## Подтверждённые возможности Q1–Q6

Все шесть проб приняты в пределах **8 запусков / 30 минут**. Две первые
неудачные попытки Q1/Q5 сохранены; счётчик не обнулялся.

| Проба | Фактическое доказательство |
| --- | --- |
| Q1: Hermes / Sol high | Инструментальный цикл Responses: поиск, извлечение именно найденного URL, цитата первичного источника; загружен функциональный contract |
| Q2: Luna high | Успешное чтение инструментом, structured result и native session metadata модели/effort/sandbox |
| Q3: Astra high | Read-only консультация: найдено пустое пересечение несовместимых диапазонов зависимостей |
| Q4: Opus high | Native Read и Context7 resolve/query, последующий structured ответ через локальный прокси |
| Q5: Sol high | Playwright открыл страницу, выставил 390×844, сделал screenshot; native image tool действительно получил это изображение |
| Q6: report adapter | Точный production launcher; pinned CLI/profile/settings/bwrap; ОС запретила запись продукта; хеш продукта неизменен; наблюдаемые server search/fetch равны нулю |

В Q5 разрешены только необходимые браузерные инструменты в изолированном
конфиге. Рабочая глобальная политика approvals не менялась. Доступность этих
маршрутов не доказывает качество моделей на произвольных задачах или отсутствие
ошибок поставщика. Название модели подтверждено клиентскими метаданными, а не
независимой аттестацией upstream.

Уточнение Q6: утверждение модели, что ей доступен `web_search`, не считается
доказательством наличия инструмента. Первоначальный receipt преувеличивал этот
факт; отдельное уточнение сохраняет исходные bytes и pins. Подтверждены только
наблюдаемые нулевые вызовы, настройки launcher и фактический запрет записи.

## Миссии и ограничения автономности

Результаты P1–P6 дополняются по завершении текущего исполнения. P1 уже принята:
Luna исправила ровно опечатку, финальный controller proof прошёл.

До успешного P1 сохранены две затраченные попытки: ошибка подготовки каталога
до запуска и отказ API из-за `allOf` до инструментов. Контроллер подтвердил
неизменность продукта и сохранённые traces. Исправлена ошибка disposable harness:
он ограничивал продукт двумя попытками при утверждённых планом трёх. Использована
третья попытка без возврата счётчиков и продления исходного срока.

В P2 продукт Sol успешно сохранён. Первый отчёт Opus отклонён из-за положительных
`findings`. Продукт не выполнялся повторно. После проверки завершения процесса,
неизменности workspace и всех bindings контроллер отдельно закрыл неясный статус
ревизора; назначена одна новая проверка того же продукта с исправленной схемой.
**Это ручное решение контроллера, а не доказательство автоматического восстановления
отчёта ревизора.** Штатный report-only recovery пока применяется к продукту.

Повторный P2-review-2 затем вернул корректный native result: `verdict=pass`,
`findings=[]`, все три binding-хеша совпали, продукт и его тесты прошли. Gateway
создал canonical result, но controller acceptance отверг его до принятия: review
order разрешал только `custody/**`, тогда как результат честно ссылался на
`endpoint.py`, `test_endpoint.py` и `README.md` из product workspace. Это
ошибка подготовки read-only order scope, а не дефект продукта или модели.
Raw result, closure, rejected acceptance и process stop сохранены. Review-3 и
повтор продукта запрещены; P3–P6 не запускаются, поскольку последовательный
пилот остановлен на P2. Исправление должно расширять read-only review scope до
зафиксированных product paths либо требовать custody-only artifact references,
с отдельной regression-проверкой. Текущий запуск не был нормализован вручную.

## Независимое ревью и решение об установке

Два новых запроса native Claude/Opus high через локальный прокси остановлены
после 300 секунд каждый. Оба stdout пусты; вердикта нет. Второй запрос получил
сокращённый пакет 37 831 bytes вместо 87 680. Исходники и входы привязаны хешами.
Исправление вариантов reviewer-схемы сделано уже после этих запросов и ими не
покрыто. Проверки Opus внутри пилотных заданий относятся к их небольшим продуктам,
не заменяют ревью исходников CENTURION.

Лимит source review этого окна исчерпан; третьего скрытого запуска не было.
Не установлено, отменил ли локальный timeout вычисление у upstream-поставщика.
Готовность к локальному развёртыванию не подтверждена, поэтому разрешённая
условная установка не начата.

Миграция подготовлена для существующих Codex/Claude/Hermes homes: 332 точных
preimages, dry-run трёх клиентов, выбор существующих domain skills, точечные
retire/replace и процедура резервирования/отката. Пользовательские политики
Codex/Hermes содержат старые маршруты; подготовлена узкая version-scoped оговорка
с сохранением исходного текста. Она не применена. Сохранение байтов политики
само по себе не доказывает совместимость её смысла с 3.0.

До установки ещё обязательны завершённая приёмка пилота и независимого source
review, фиксация исходников, свежая проверка preimages, совместимость политик,
резервные копии, безопасное окно без активных заданий, установка, readback и
реальный canary установленной цепочки. Исходное разрешение владельца на этот
условный rollout остаётся действующим; push, публикация и tag не разрешены.
