## 2. Как выполнено ревью Claude

Пользователь явно запросил Claude через локального провайдера. Whitelist-параметры найдены в `/home/mrz/.bashrc`: `ANTHROPIC_DEFAULT_OPUS_MODEL=claude-opus-5-5`, `ANTHROPIC_BASE_URL=http://127.0.0.1:8317`. Каталог вернул модель, затем выполнен реальный `POST /v1/messages`, без credentials. Catalog/HTTP 200 отдельно не считаются завершённым ревью.

Использован ограниченный `CLAUDE_ORDER v1`: read-only входы, `ExecutionDecision`, свежий artifact namespace и snapshot вне рабочей области. Модель получила текст пакета через API; tools не передавались, доступа к файловой системе у вызова не было. Программный контроллер сохраняет raw response и проверяет результат штатным валидатором/guard. Это применение [evocate-ad-opus](/home/mrz/.agents/skills/evocate-ad-opus/SKILL.md) и репозиторного [claude-order](../integrations/claude-legion-kit/plugin/skills/claude-order/SKILL.md); локальная ссылка на установленный skill не является частью runtime-поставки.

Запрошены Opus 5.5 и effort high. Provider-reported модель проверяется в receipt. Это доказательство сообщённого маршрута, не независимая аттестация внутренней модели поставщика. Никаких секретов/домашних конфигураций сверх двух явно указанных несекретных параметров в пакет не включалось.
