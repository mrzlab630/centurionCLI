# Proportional proof

Completion requires same-run evidence for the approved acceptance criteria.
Select the smallest relevant existing check or direct readback; inspect the target
behavior and artifacts, not only an exit code. Report unrun checks and limitations.
A failed check authorizes no scope expansion. Correct an in-scope defect only within
the mission's remaining attempt budget; report unrelated failures to the lead.
There is no fixed coverage threshold or automatic retry count. Reviewer findings
return to the lead for a bounded correction order; reviewers never fix product.
