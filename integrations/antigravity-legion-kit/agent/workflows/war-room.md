# WAR ROOM Workflow

When invoked:

1. Read local instructions and current git state.
2. Identify phase/scope and current source of truth.
3. Produce a brief plan if implementation is non-trivial.
4. Implement narrowly.
5. Verify with same-session evidence.
6. Report root cause, change, and proof.

Use Opus for adversarial review when available. Use Gemini Pro for planning and architecture. Use Gemini Flash only for bounded search/summarization or low-risk edits.
