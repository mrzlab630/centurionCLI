# Interface Polish Pass Workflow

1. Identify the component/screen and its intended workflow.
2. Check spacing, alignment, text fit, states, hit areas, contrast, and motion.
3. Fix the smallest set of details that makes the UI feel intentional.
4. Preserve existing product style and component API.
5. Verify mobile width 320-390px and desktop behavior when feasible.
6. Report before/after changes and proof.
