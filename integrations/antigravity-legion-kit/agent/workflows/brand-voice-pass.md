# Brand Voice Pass Workflow

1. Gather existing copy from UI, docs, README, product notes, and user-supplied examples.
2. Extract a concise voice profile: rhythm, specificity, vocabulary, claims, taboos.
3. Draft copy variants only after the profile is clear.
4. Check every claim against implemented product behavior.
5. Keep one primary CTA per screen/message.
6. Report the voice profile used and the changed text.
