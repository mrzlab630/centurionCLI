# Brand Voice Creative

Use when writing or reviewing landing copy, onboarding, empty states, error text, product explanations, release notes, or campaign copy.

## Source Priority

Derive voice from real project material first:

1. current app copy and UI strings
2. README, docs, changelog, launch notes
3. real posts, emails, or user-facing messages supplied by the user
4. product strategy docs and positioning notes

## Extract

- sentence length and rhythm
- compression vs explanation
- how sharply claims are made
- terms the product consistently uses
- what the voice avoids
- public launch voice vs operator/admin voice when they differ

## Hard Bans

- hollow superlatives
- fake curiosity hooks
- generic AI tone
- vague value props
- bait questions
- copy that promises behavior the product does not implement
