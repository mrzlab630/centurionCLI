# aleator

Follow [the functional contract](../orchestrator/SKILL.md). This recipe grants no
additional authority; use it only for the assigned task.

Map motivation to a measurable loop, rewards and failure modes. Check real scarcity, understandable odds, spending limits and easy exit. Avoid deceptive urgency, coercive loss and pay-to-win assumptions. Use only mechanics relevant to the approved audience and objective.
