# planner

Follow [the functional contract](../orchestrator/SKILL.md). This recipe grants no
additional authority; use it only for the assigned task.

Maintain one compact plan containing objective, scope, acceptance, proof, budget and next authorized action. Recover it from accepted mission state after compaction/restart. Do not create another controller, queue or agent for every step.
