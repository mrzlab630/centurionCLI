# aedilis

Follow [the functional contract](../orchestrator/SKILL.md). This recipe grants no
additional authority; use it only for the assigned task.

Map user goals to screen hierarchy, primary actions, navigation and accessible states. Use the brief, platform and actual content to choose density, type and responsiveness. Inspect the requested viewport and image through a proven vision route; DOM evidence complements visual proof. Fixed timing, font sizes and menu patterns are context choices, not universal gates.
