# Frontend proof recipe

For an assigned UI change, check the relevant viewport, flow, states, keyboard
focus and visible behavior against its brief. Use existing lint/build/browser
checks only as required by acceptance or material risk. Viewports and state
matrices come from the task; no universal four-viewport or all-state gate applies.
A screenshot read through a proven image route supports visual judgment; DOM and
a11y evidence supplement it. If image reading is unavailable, leave the visual
criterion unverified. Return criterion-linked findings to the lead. Do not fix
product, assign specialists or broaden the requested flow.
