# Content Clarity

Use this file for plain language, content-design review, accessibility, inclusivity, and clarity checks. It draws on plain-language/content-guide patterns such as 18F/GOV.UK-style content design without treating any archived guide as a live dependency.

## Plain Language

- Use common words unless a precise product term is required.
- Lead with the action or decision the user needs.
- Use active voice where it improves clarity.
- Keep sentences short in UI; break complex explanations into steps.
- Put conditions before the CTA when the condition changes the user's choice.

## Accessibility

Copy supports accessibility when it:

- Makes controls understandable without color or icon alone.
- Gives specific error recovery.
- Avoids directional-only instructions like “click the button on the right”.
- Uses link text that describes destination/action.
- Avoids all-caps paragraphs and excessive punctuation.
- Works when read by a screen reader out of visual context.

## Inclusive Copy

- Avoid shame and blame.
- Avoid implying user carelessness in errors.
- Avoid culture-specific idioms in core workflows.
- Use neutral examples unless domain requires specificity.
- For identity, location, age, legal, or financial topics, prefer precise and respectful terms.

## Reading Order

For a screen or modal, copy should answer in order:

1. Where am I?
2. What is happening?
3. What can I do?
4. What happens next?
5. What if I cannot do it?

## Jargon And Terms

Jargon is allowed only when:

- The audience expects it.
- The term is more precise than the plain alternative.
- It appears in glossary or is explained on first use.
- It does not hide risk, cost, or eligibility.

## Legal And Policy Copy

- Do not oversimplify legal obligations into misleading CTAs.
- Do not bury conditions in tooltip-only text.
- Use clear summaries plus a link to full rules.
- Payment, prize, privacy, and safety copy should be conservative and reviewable.

## Clarity Checklist

- [ ] The first sentence is useful.
- [ ] The CTA matches the actual action.
- [ ] Error copy tells the user how to recover.
- [ ] Empty state has a next step.
- [ ] Terms are consistent with glossary.
- [ ] No unsupported claims.
- [ ] No fake urgency or scarcity.
- [ ] No placeholder-only labels.
- [ ] Link text is descriptive.
- [ ] Copy can be localized without English word-order assumptions.
